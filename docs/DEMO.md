# 90-second demo

Record on `localhost` with Ollama, not the hosted site, so the offline moment is real.

## Before you record

- [ ] Ollama running, models pulled, backend and frontend running
- [ ] Do 4–5 real missions first with different feelings, so History has several bars
- [ ] Check the heron memory test: "a grey heron by the river", then "another heron near the water"
- [ ] Pick a time slider value of 20 minutes, close other tabs, silence notifications

## Shot list

| Time | Show | Say |
|---|---|---|
| 0–8s | A feed scrolling | "Every app wants more of your time. What if this one wanted less?" |
| 8–20s | Home: 20 min, low energy, birds → CREATE MY MISSION → breathing screen | "This model is running on my laptop. No GPU, no cloud." |
| 20–35s | Zoom on the status strip, turn Wi-Fi off, create another mission | "Wi-Fi is off. Same app, same model, nothing leaving this machine." |
| 35–50s | Mission card: style pill, the "why" line, `% new`, bar draining | "It picked this style because of how you felt last time. And it checked this isn't a repeat." |
| 50–60s | Tap GO OUTSIDE → black PHONE DOWN | "Forty-five seconds of screen. Then it takes it back." |
| 60–72s | You walking outside, no voiceover (film for real) | — |
| 72–82s | Back inside: type a note, FINISH, the reflection with "Linked to an earlier note" | — |
| 82–90s | History: "What works for you" bars | "It learns what works for you, and it all stays on this laptop. The best AI interaction is the one that ends with you leaving the room." |

## If something goes wrong

Slow model (about 11 s): keep the breathing screen in the cut, it is part of the design. Model down: the card shows "OFFLINE-SAFE MISSION", which is also worth showing.
