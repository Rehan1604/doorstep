# Contributing

Thanks for helping people spend less time on screens.

1. Fork the repo and create a branch.
2. Run the app locally (see the README quick start).
3. Make a focused change. Keep functions small and add a test.
4. Run `cd backend && python -m pytest -q` and `cd frontend && npm test`. Both must pass.
5. Open a pull request describing what changed and why.

**Please don't:** add feeds, streaks, leaderboards or anything designed to increase screen time. **Never** commit API keys. Be honest in docs: label simulations as simulations and measured numbers with the hardware they came from.e
